# Eight-page proposal outline (English), weighted to the scorecard
Innovation 25 · Applink 20 · Technical 20 · Business 20 · Impact 10 · Presentation 5. Claim only completed work; label everything else "proposed".
1. Identity: title, team, track, organisation. 2. Summary: problem, proposal, beneficiaries, why now. 3. Problem: WHO/DGHS evidence, operational friction, existing initiatives. 4. Solution: report → review → prioritise → assign → act → verify journey. 5. Technical: stack, CARE, state machine, integrity controls, tests actually run. 6. Applink: real integration evidence (request ids, delivery status), user flows; state honestly what is pending. 7. Business: payers, pricing hypotheses, six-month plan, distribution. 8. Differentiation: genuine pilot evidence and the complete status timeline (the memorable page).
