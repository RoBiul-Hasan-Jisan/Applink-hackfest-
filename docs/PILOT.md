# Pilot plan (proposed, not confirmed)
One permitted site in Chattogram (a campus such as East Delta University is a *candidate*, not a partner). Needed before any claim: written site/participant permission; authorised reviewers and responders named; consent text approved; an Applink-approved test number.
Minimum real evidence: observation (photo or text, real time, consent) → Applink SMS request id + recorded status → reviewer decision with reason → authorised assignee acceptance → real action evidence → independent verification or an honest "unresolved" → full audit timeline.
Never stage a hazard or invent a cleanup. **Zero hazards is a valid result:** demonstrate the real report path, real SMS, and the honest empty state.
Go/no-go: Nov 25 Applink status known (one flow tested or a documented blocker); Nov 27 end-to-end review→task transitions on real inputs; Nov 28 no critical privacy/authz/audit gaps; Nov 30 only finished functionality shown.
