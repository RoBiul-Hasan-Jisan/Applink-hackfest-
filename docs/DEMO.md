# Two-minute demo (AppQuest limit: <= 2 minutes). Show ONLY what genuinely works.
Prep: real approved Applink test number, one genuine observation (or the honest empty state), reviewer + volunteer logged in. If Applink provisioning is pending, **say so on screen** and do not present the simulator as live.
- 0:00 Problem in one line: reported ≠ inspected ≠ resolved.
- 0:15 A real resident observation arrives (photo + consent, or SMS `REPORT WATER <area>`); report code returned; **NEW: awaiting review**.
- 0:35 Reviewer opens the queue: sees evidence, rule-based priority with reasons, CARE notes (evidence completeness, duplicate check); approves (or overrides with a reason).
- 0:55 **Applink moment**: assignment SMS to the authorised volunteer; show the real request id in the Telecom ledger (accepted vs delivered).
- 1:10 Volunteer replies `ACCEPT <code>`, records real action evidence, `DONE`.
- 1:30 Coordinator verifies; resident SMS asks 1/2; show reopen path and the immutable timeline.
- 1:45 Data integrity page: sources, checksums, "no synthetic data" count.
- 1:55 Close: honest evidence, accountable action, telecom access that works.
