# Data integrity
Provenance is a product feature: `GET /api/integrity` and the **Data integrity** page show genuine report counts by source/status/evidence completeness, the evidence ledger (id, type, size, SHA-256), priority rule versions and overrides, imported risk models with evaluation status and coverage, and the telecom accepted-vs-delivered ledger.
Rules: records flagged `isSynthetic` (tests/simulator) are excluded from every figure; missing data stays missing; risk estimates are context only unless `validated`; a report is an observation, not a confirmed breeding site; CARE output is deterministic notes (evidence completeness, duplicate suspicion, feasibility) and abstains explicitly when evidence is thin. ML inputs are hashed (`ml/src/preprocessing.py`) and the pipeline reports `INSUFFICIENT_EVIDENCE` rather than inventing a model.
